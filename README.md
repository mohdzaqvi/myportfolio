# Mohd Zaqvi — Portfolio

A static portfolio with full-screen scroll scenes, zoom transitions and a photo rendered as data particles.

## Run locally
Open index.html in a browser. No installation or build is required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example: portfolio).
2. Upload index.html and .nojekyll at the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. GitHub displays the live website URL after deployment completes.

## Edit
All HTML, CSS, JavaScript and the embedded portrait are in index.html.
Search for Mohd, Zaqvi, zaqvimohd@gmail.com or the LinkedIn URL to update details.
Use the MOTION ON/OFF button to control scroll effects.

No backend, API keys or paid dependencies are needed.
